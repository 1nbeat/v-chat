# 唯心 VChat

一个轻量级中文 AI 聊天应用。它提供多机器人单聊、机器人对聊、人格预设、个人资料和本地会话管理，并通过 Node.js 服务端代理模型请求，避免将模型密钥暴露到浏览器。

演示地址：https://chat.arifun.com

## 功能概览

### 多机器人单聊

- 内置默认机器人“唯心 VChat”，支持创建、编辑和删除自定义机器人。
- 每个机器人可分别配置昵称、签名、头像、人格预设和补充设定。
- 支持使用人格预设，也支持直接填写专属系统提示词。
- 每个机器人拥有独立的单聊上下文和本地历史记录。
- 从最近会话中选择机器人时，会恢复该机器人的既有聊天记录。
- 聊天窗口支持欢迎语快捷提问、Enter 发送、Shift + Enter 换行和输入框自动增高。

### 人格与提示词

- 内置陪伴者、导师、专业顾问、创意搭档、编程搭档、学习教练等人格预设。
- 全局规则会添加到每个机器人专属系统提示词之前。
- 单聊顶部悬浮机器人头像可查看其人格摘要或专属系统设定。
- 新对话的机器人选择列表显示头像、昵称与签名；悬浮头像同样可查看人格信息。

### 自定义模型

- 支持新增、编辑、删除多个自定义模型配置，并可在设置中随时切换。
- 每个配置可分别保存 API 地址、API Key 和模型名称；空字段会回退到项目 `.env` 默认值。
- 可一键切回项目默认配置；已有单份自定义模型配置会自动迁移到列表中。

### 机器人对聊

- 选择两个不同机器人和一个主题后，可让它们围绕主题交替对话。
- 每个机器人以自身视角接收历史：自己的发言作为 `assistant`，另一机器人的发言作为 `user`。
- 可配置单次自动对话轮数、单会话总轮次上限和轮次间隔。
- 支持停止当前对聊，以及在未达到总上限时追加轮数继续对聊。
- 双聊主题会异步生成一条简短概述。
- 最近最多保留 10 条双聊会话记录。

### 展示与资料

- AI 回复可开关 Markdown 渲染，支持标题、列表、引用、链接、行内代码和代码块。
- 代码块提供简易关键字高亮。
- 支持设置本地昵称和头像；支持 PNG、JPG、WebP、GIF，文件上限为 1 MB。
- 支持机器人头像，未设置头像时使用名称首字作为默认头像。
- 支持清空当前单聊或双聊记录，并在删除等不可逆操作前要求确认。

## 技术架构

```text
浏览器页面
  -> POST /api/chat
  -> Node.js 服务端代理
  -> 兼容 OpenAI Chat Completions 的模型 API
```

前端由原生 HTML、CSS 和 ES Modules 构成，无需构建步骤。Node.js 原生 `http` 服务负责两项工作：

1. 从 `public/` 目录提供静态资源。
2. 接收浏览器的 `/api/chat` 请求，优先使用用户在“自定义模型”设置中填写的配置，未填写的字段回退到服务端默认配置后转发到上游模型服务。

自定义模型的 `apiUrl`、`apiKey` 和 `model` 不会作为明文字段发送：浏览器使用随机 AES-GCM 会话密钥加密这些参数，再用服务端 RSA-2048 公钥通过 RSA-OAEP-SHA-256 加密会话密钥；服务端解密后再转发。该机制仍必须配合 HTTPS 使用，否则攻击者可以替换页面或服务端公钥。

项目默认模型请求由部署该项目的服务器发出，`.env` 中的 `AI_API_KEY` 不会发送给浏览器。用户自定义的 API Key 会保存在当前浏览器的本地配置中，并通过 `/api/chat` 发送给服务器代理；部署时必须同时运行 `server.js`，仅托管 `public/` 静态目录无法完成聊天请求。

## 快速开始

### 环境要求

- Node.js 18 或更高版本
- 一个兼容 OpenAI Chat Completions 接口的模型服务及其 API Key

### 安装与配置

```bash
npm install
cp .env.example .env
```

编辑 `.env`：

```env
AI_API_KEY=replace_with_your_api_key
AI_API_URL=https://tokenhub.tencentmaas.com/v1/chat/completions
AI_MODEL=hunyuan-role-latest
PORT=3000
```

各字段含义：

| 变量 | 说明 |
| --- | --- |
| `AI_API_KEY` | 上游模型服务的默认访问密钥，保存在服务器侧；用户也可以在页面中填写自己的 Key。 |
| `AI_API_URL` | 上游 Chat Completions API 地址。 |
| `AI_MODEL` | 默认使用的模型名称。 |
| `PORT` | 本地服务监听端口，默认 `3000`。 |

### 启动

```bash
npm start
```

开发模式使用相同命令：

```bash
npm run dev
```

浏览器访问 `http://localhost:3000`。

## 数据存储与隐私

机器人、用户资料、自定义模型配置列表、全局规则、单聊记录、双聊记录和展示设置均保存在当前浏览器的 `localStorage` 中，不会写入项目服务端数据库。

这意味着：

- 同一浏览器可在刷新页面后恢复会话。
- 清除浏览器站点数据会删除本地聊天记录和配置。
- 不同浏览器、设备或用户之间不会自动同步数据。
- 上传的头像以 Data URL 形式保存在浏览器本地存储中。

## 部署说明

将整个项目部署到支持 Node.js 的服务器，并通过环境变量或服务器侧 `.env` 配置模型密钥。启动 `node server.js` 或 `npm start` 后，再由反向代理将公网流量转发到应用端口即可。

不要将 `.env` 提交到版本库，也不要把项目默认 `AI_API_KEY` 写入 `public/` 下的浏览器代码。用户在页面中填写的自定义 Key 会保存在浏览器本地，请仅在可信环境中使用。自定义模型参数虽然使用应用层加密传输，但 API Key 仍会明文保存在当前浏览器的 `localStorage` 中；生产环境必须使用 HTTPS。

## 限制与注意事项

- 当前实现使用非流式响应，模型完整返回后才会显示最终回答。
- 每次单聊请求都会携带当前机器人的完整历史，长会话可能受到上游模型上下文长度限制。
- Markdown 渲染为内置轻量实现，不等同于完整 Markdown 规范。
- AI 回复可能不准确；重要的医疗、法律、财务或安全决策应由合格专业人士确认。
